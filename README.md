This project is a submission for the Sprint Asia technical assessment.
It is built using Go (Golang) for the backend API and ReactJS for the frontend interface.

🚀 Tech Stack

Backend:

Go 1.22+

Gin Framework

GORM ORM

SQL (MySQL/PostgreSQL)

Docker (optional)

Frontend:

ReactJS (Vite)

Axios

TailwindCSS

    ├── package.json
    ├── src/
    └── ...other frontend files

⚙️ Backend Setup

Navigate to the backend directory:

cd backend


Install all dependencies:

go mod tidy


Run the application:

go run .


The backend will start on the configured port (e.g., http://localhost:8000).

💻 Frontend Setup

Navigate to the frontend directory:

cd fe


Install dependencies:

npm install


Run the application:

npm run dev


The frontend will start on http://localhost:5173 (by default).
